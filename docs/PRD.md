# Product Requirements Document (PRD)

## 1. 제품 개요

### 1.1 제품명

- Uphill

### 1.2 제품 설명 (한 문장)

- AI를 활용한 공간 기반 루틴 추천 시스템

### 1.3 프로젝트 배경 및 동기

- 기존 루티너리 앱들이 수행 능력 향상에 크게 도움이 되지 않는 것을 확인
- Uphill은 공간 스캔을 통한 가구를 확인 후 루틴에 따른 가구 재배치를 추천하여 루틴 수행 능력을 향상을 지원

---

## 2. 목표 및 목적

### 2.1 비즈니스 목표

- 기존 루티너리 앱들과 차별된 이용자 수행 능력 향상에 집중

### 2.2 사용자 문제 정의

- 기존 루티너리 앱의 유연하지 못한 일정 수정 기능
- 공간을 루틴 환경에 맞추기가 어려움

### 2.3 해결 방안

- 공간 스캔을 활용한 가구 구성을 파악 후 LLM을 통해 루틴에 맞는 가구 구성 배치를 추천
- 변동 가능한 루틴 여부를 입력 받아 루틴 수행 시간이 달라질 시 유연한 계획 재구성
